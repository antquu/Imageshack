Pourquoi pas de base de données ?Why no database?

ImageShack ne stocke rien. Le lien court contient directement le nom du fichier chez l'hébergeur. Pour Catbox, /c/… va chercher le fichier sur files.catbox.moe et le renvoie. Pour NoelShack, /i/… va chercher la même image sur NoelShack et la renvoie.

Résultat : aucun compte, aucune base de données, et vos liens marchent tant que le fichier existe chez l'hébergeur.

ImageShack stores nothing. The short link directly contains the file's name at the host. For Catbox, /c/… fetches the file from files.catbox.moe and sends it back. For NoelShack, /i/… fetches the same image from NoelShack and sends it back.

The result: no account, no database, and your links keep working as long as the file exists at the host.
